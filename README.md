## Weather Application Api

This is an Application for viewing live weather data for a given location using the open weather api

# it should provide

- Temperture
- Humidity
- Descreption
- A relevant Emoji for the weather state

all by the name of the location you want to view the data for i.e miami, oran, ...

## instalation

install via github

```bash
git clone https://github.com/nazimdev276/weatherApp.git
```

## configeration

then go into the folder and create a config.js file and save your openweather api key as follows

```javascript
const apiKey = "<PASTE YOUR API KEY HERE>";
```

then all that is left is to open the Application in the browser "localhost"
